# EyeSee - Diabetic Retinopathy Detection System

EyeSee is an AI-powered web application built with Flask and TensorFlow/Keras to detect and evaluate stages of Diabetic Retinopathy from retinal fundus images using an Xception deep learning architecture.

## Features
- **User Authentication:** Login and Registration system with session management.
- **Live Image Preview:** Real-time client-side image preview before submission.
- **Automated Diagnosis:** Instant stage prediction powered by an Xception CNN model.

## Installation & Setup

1. **Clone or Download the Repository**
2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
   Access the App:
Open http://127.0.0.1:5000/ in your web browser.
